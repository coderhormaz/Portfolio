# Portfolio — Hormaz Daruwala

My current personal portfolio site. Built with Next.js 16 and React 19, with smooth scrolling, animated project modals and a custom cursor.

## Features

- Project showcase with animated project detail modals
- Custom cursor
- Smooth scrolling with Lenis
- Motion throughout via Framer Motion
- SEO metadata set up for the site

## Tech Stack

- Next.js 16, React 19, TypeScript
- Tailwind CSS 4
- Framer Motion
- Lenis (smooth scroll)

## Getting Started

Prerequisites: Node.js and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view it locally.

Production build:

```bash
npm run build
npm run start
```
